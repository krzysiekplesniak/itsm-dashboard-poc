ITSM Dashboard Kit

From ITSM exports (CSV) to a verified, clickable KPI dashboard. The numbers are computed by code, the knowledge of how to build a Service Desk dashboard lives in skills, and you choose how to use it: chat with the agent or install the plugin.

1 · Agent on GitHub Copilot

Web app with a chat: upload exports, answer a few questions, get the dashboard. Runs in GitHub Codespaces on your Copilot licence.

Open in Codespaces
  1. In the terminal: copilot login
  2. cd app && npm start
  3. Open the forwarded port 3000
2 · Plugin (skills + engine)

The same knowledge for Claude (Cowork, Claude Code) or GitHub Copilot (VS Code, CLI). The only difference from a plain LLM: the plugin is installed.

Download the plugin

Copilot CLI: copilot plugin install {{REPO}}:plugin

3 · Dashboard in your browser

No server, no upload: paste a spec, drop your CSV files, the page computes every KPI locally.

Open the dashboard app

Example spec · Demo on synthetic data

4 · Chat without skills

For assistants that cannot load skills: attach the knowledge file and paste the prompt.

ITSM_KNOWLEDGE.md · PROMPT.md

Data rules

Only anonymised exports. Every file passes a personal-data check first; uncertain columns wait for your decision. Nothing on this site uploads data: the browser app works offline. Examples use synthetic data only.
